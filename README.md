# motion-canvas-playground

Experiments with [Motion Canvas](https://motioncanvas.io), plus a thank-you video for viewers of my YouTube channel.

## What's inside

- `src/scenes/anujbarve/`: the thank-you video, built from viewer comments, doubts and suggestions
- `src/scenes/`: smaller experiments with titles, positioning, layout, the camera and formulas
- `public/`: screenshots of public YouTube comments used in the video

## Run it

```bash
npm install
npm start
```

This opens the Motion Canvas editor. Scene order and audio are set in `src/project.ts`.
